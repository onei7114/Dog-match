# Quickstart: Dog Match

## Local preview

1. Open the repository root in a browser, or serve the project locally.
2. The simplest option is to run a local static server from the project folder:

```bash
cd "C:\Users\nonei\Documents\GitHub\vibe-coding-hw2"
python -m http.server 8000
```

3. Visit http://localhost:8000 in a browser.
4. Upload a supported dog image or click a popular breed card to see the result experience.

## Manual validation checklist

- Drag-and-drop an image to confirm the upload state responds correctly.
- Try a rejected file type or oversized file to verify error messaging.
- Confirm the result card updates to show breed, confidence, and trait values.
- Verify favorite toggles and breed scrolling remain accessible and usable on mobile.
- Ensure text clearly says the breed guess is a likely match rather than certainty.
